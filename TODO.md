# Entregas de ITM Project Hub

- [x] **Centro ejecutivo y alertas.** Mostrar total de proyectos, avance promedio, proyectos en riesgo, hitos vencidos y distribución por semáforo verde, amarillo y rojo; mostrar alertas visibles para proyectos críticos y permitir abrir el proyecto desde cada alerta.
- [x] **Proyectos y metodología.** Crear y editar proyectos; abrir la vista detallada de cada proyecto con cinco etapas y, en cada etapa, actividades, entregables, responsables, fechas, estado y avance; gestionar entregables, hitos, riesgos y RAID vinculado. Usar las cinco metodologías del catálogo ITM como métodos distintos, sin confundirlas con las cinco etapas.
- [x] **Tareas operativas.** Crear y editar tareas con estados Por Hacer, En Proceso, En Revisión y Completado; prioridades Baja, Media, Alta y Urgente; horas estimadas y reales; subtareas; temporizador; mostrar vistas Tabla y Kanban.
- [x] **Seguimiento de equipo.** Mostrar carga de trabajo con base en horas disponibles configurables y esfuerzo abierto asignado a cada persona.
- [x] **Reportes y catálogo.** Ofrecer KPIs y resumen ejecutivo, y catálogo de metodologías, herramientas y entregables derivados del kit ITM.
- [x] **Intercambio y respaldo.** Almacenar localmente; importar y exportar JSON; importar y exportar CSV; validar formato y estrategia combinar/reemplazar; conservar una exportación completa.
- [x] **Microsoft 365.** Diseñar e implementar la base de integración con Microsoft Graph para Outlook Calendar y Microsoft To Do; mostrar en la interfaz qué ya funciona y qué requiere Azure/Entra, redirect URI, credenciales y permisos.
- [x] **Documentación entregable.** Incluir arquitectura y estructura de carpetas/módulos, código completo y organizado, instalación y ejecución, flujo funcional, supuestos y datos reales que deberá completar el equipo.
- [x] **Interfaz en español.** Mantener diseño profesional orientado a gestión de proyectos y procesos, coherente con la paleta y el patrón del kit ITM y adaptable a móvil.
- [x] **Validación funcional y visual.** Inspeccionar escritorio y móvil; comprobar las rutas de Preview, incluido `GET /manus-routes.json`; ejecutar el control de tipos, ocho pruebas y compilación de producción.
